mini-agent

A small modular CLI harness for model-router and other OpenAI-compatible Chat Completions APIs, with resumable durable runs for longer tasks.

curl -fsSL https://raw.githubusercontent.com/Mitriyweb/mini-agent/main/install.sh | bash

CLI + REPL

Run tasks directly or iterate in a live interactive shell with workflow shortcuts and skills.

OpenAPI support

Inspect JSON and YAML specs, list routes, and validate common spec issues with the built-in openspec tool.

Safe by default

Workspace-only file access, approval gates, and bounded step limits reduce accidental drift and runaway loops.

Durable runs

Start a named run, keep redacted checkpoints on disk, and resume interrupted or recoverable failed work without repeating completed tool calls.
